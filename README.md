# R3.01 — Memory Game

A simple memory game built with JavaScript as part of the university course **R3.01 Développement Web**.

## Objective

Find all matching pairs of cards in as few moves and as little time as
possible.

## How to play

1. Open the game in a web browser.
2. Click a card to reveal it.
3. Click a second card to find its pair.
4. Continue until every pair has been matched.

## Project

This project was created for educational purposes.
